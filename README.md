
# OIBSIP – Web Development Internship  
## Level 1 – Landing Page Project  

### Project Overview  
This project is a **responsive Landing Page** created during my Oasis Infobyte Internship. It showcases fundamental front‑end development skills using **HTML and CSS**, focusing on clean design, usability, and responsiveness across devices.  

---

### Features  
- Navigation bar with smooth scrolling  
- Hero section with headline and call‑to‑action button  
- About Us section with descriptive content and visuals

- Testimonials section for user feedback  
- Contact form and footer with social links  
- Fully responsive layout (mobile, tablet, desktop)
