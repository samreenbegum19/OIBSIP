# OIBSIP - Web Development Internship  
## Level 1 - Landing Page Project

### 📌 Project Overview
This project is a **responsive Coffee Shop Landing Page** built using **HTML and CSS** as part of the Oasis Infobyte Internship Program.  
It demonstrates core front-end development skills including layout design, styling, and responsiveness.

---

### ✨ Features
- Sticky navigation bar  
- Hero section with headline and call-to-action button  
- Menu highlights (Espresso, Cappuccino, Latte)  
- About Us section with image and description  
- Customer testimonials section  
- Contact/Footer with café details and social links  
- Fully responsive design (mobile, tablet, desktop)
